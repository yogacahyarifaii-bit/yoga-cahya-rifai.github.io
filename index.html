Tentang Saya

Teknis, fleksibel, dan terus berkembang.

Saya tidak membatasi diri hanya pada satu bidang. Pengalaman lapangan di jaringan dan fiber optic saya lengkapi dengan kemampuan komputer, Microsoft Office, dan Frontend Development.

Nama saya Yoga Cahya Rifai. Saya adalah lulusan SMK Candra Naya jurusan Teknik Komputer dan Jaringan (TKJ). Dari pendidikan tersebut saya membangun dasar dalam komputer, jaringan, troubleshooting, dan berbagai pekerjaan teknis.

Setelah lulus, saya membawa pengetahuan tersebut ke dunia kerja. Saya pernah menjadi Fiber Optic Technician di Moratel, FTTH Field Engineer di Tabisnet, dan Technical Support di ION. Dari pengalaman itu saya terbiasa melakukan instalasi, maintenance, testing, troubleshooting, analisis masalah, serta bekerja langsung di lapangan.

Di sisi networking, saya memiliki MTCNA — MikroTik Certified Network Associate dan Sertifikat Kompetensi Junior Network Administrasi dari LSP Media Informatika/BNSP. Saya juga memiliki pengetahuan dengan teknologi MikroTik dan Cisco.

Saya juga memiliki kemampuan Microsoft Office dan sudah terbiasa menggunakan Word, Excel, dan PowerPoint. Selain itu, saya sudah membuat website menggunakan HTML, CSS, dan JavaScript, termasuk website portfolio pribadi saya sendiri. Karena itu, Frontend Development bukan sekadar minat, tetapi kemampuan yang sudah saya praktikkan secara langsung.

Saya ingin terus belajar, mencoba teknologi baru, mendapatkan pengalaman baru, dan berkembang tanpa menjadikan latar belakang SMK sebagai batasan.
