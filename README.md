# Yoga Cahya Rifai — Portfolio V2

Personal portfolio dengan konsep dark/technical untuk Network Engineering + Fiber Optic.

## File
- `index.html` — struktur website
- `style.css` — desain, animasi, responsive mobile
- `script.js` — menu mobile, terminal typing, reveal animation, project modal
- `profile.jpg` — foto profil
- `README.md` — panduan

## Sebelum publish
1. Link GitHub, LinkedIn, Instagram, WhatsApp, dan email sudah terpasang.
2. Pastikan email di bagian Contact sudah benar.
3. Jika ada pengalaman/perusahaan/tanggal yang ingin ditampilkan secara spesifik, edit bagian Experience.
4. Upload semua file ke repository GitHub.
5. Deploy repository tersebut ke Vercel.

## Catatan
Project card sudah bisa diklik dan membuka modal detail. Foto profil yang diberikan sudah dimasukkan sebagai `profile.jpg`.
